# Game Brief: Director's Cut

> 工作名。范围的唯一闸门是 `design/prd/master-prd.md`;本页是它的一页摘要,冲突时以 PRD 为准。

**One-sentence pitch:** 奇幻斜俯视割草——出发前用胶片卡剪辑难度,局内搜到的宝物越多怪越强,你要决定是用掉保命,还是冒险带出去建营地。

## Core loop
- 营地:分解/囤积,升级建筑 → 剪辑室:插胶片卡,看收益倍率(难度由你剪,不是随机)
- 局内(3–10 分钟):割草升级,搜补给箱/宝库,热度随拾取上升,怪越来越强
- 每次拾取都要选:**留着还是用掉**?用掉保命并降热度,留着才能带出去换材料
- 站满读条撤离:结算 = 材料 × 收益倍率,回营地升级建筑,再剪下一局

## Player goal & fail state — what "working" looks like
- 目标:带着尽可能多的宝物成功撤离,让营地肉眼可见地变强。一次完整循环 4–11 分钟。
- 失败:死亡则背包全丢。验收:一个没玩过的评委 15 分钟内至少 2 局、一次剪辑改变了 Boss/精英/尸潮、一次"留着还是用掉"、一次营地建筑变化。

## MVP — what must exist to be the game
1. **局内战斗**:WASD、闪避、1 把起始武器自动攻击、受伤与死亡;1 种小怪、刷怪调度、尸潮、Boss;1 张固定灰盒地图,带点位和 2 个撤离点
2. **局内成长**:经验、升级三选一,3 把武器 + 4 个被动
3. **物资与热度**:1 种材料(Iron)、补给箱和宝库、3 件遗物、背包上限、热度影响刷怪
4. **撤离与死亡**:站点读条、成功按收益倍率结算、死亡全丢
5. **局前剪辑**:2 个胶片槽、2 张卡(Horde Night、The Cut Knight)、收益倍率
6. **营地**:3D 营地点选建筑、铁匠铺和诊所、指数成本升级、仓库面板(查看 + 分解遗物)
7. **流程、存档与必需 UI**:营地 → 剪辑 → 局内 → 结算 → 营地;单存档自动保存;HUD、升级选择、背包、读条、结算、营地和剪辑面板

## Out of scope — not building this
- Should/Could 档内容在 Must 跑通前不开工:更多卡/怪/材料/建筑/武器、标题与暂停、NG 胶片、超时、免费资产替换
- 永久不做:联机、随机地图、可拖拽时间线、可行走营地、手柄、多语言、抽卡/氪金/强制联网

## Build order
1. **"留着还是用掉"**(热度 + 遗物使用 + 背包 + 撤离),全用方块灰盒;Day 1 晚找 1–2 人试玩,不好玩当晚只改这套
2. 局内战斗与成长补成完整一局(自动攻击、升级、刷怪、尸潮、Boss)
3. 局前剪辑 + 收益倍率,接到结算
4. 营地与存档:建筑升级、仓库、整圈循环,新存档能跑完两圈
5. 全部 Must UI 与灰盒可读性
6. (Must 跑通后)Should:美术/音频替换、更多内容;Day 3 晚 23:00 冻结功能

---
**Who it's for / what they feel:** 一个人、键鼠、没玩过的评委,试玩 10–20 分钟;感觉是每次拾取都在权衡,每局都看得见营地变强。

**Art & audio direction:** 先方块灰盒保可读性;之后换统一风格的免费奇幻资产,少量核心音效与 2 首音乐。

**Reference game:** Vampire Survivors(割草 + 自动攻击)× Escape from Tarkov 式撤离——只保留自动攻击一张图和"站点撤离、死亡全丢",不要多人和复杂背包。
